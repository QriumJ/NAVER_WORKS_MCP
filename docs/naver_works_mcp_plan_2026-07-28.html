02 · MCP 2026-07-28 적용

무상태 HTTP`initialize`와 `Mcp-Session-Id`를 사용하지 않고 요청별 `_meta.io.modelcontextprotocol` envelope를 요구합니다.
라우팅·캐시SDK가 `Mcp-Method`·`Mcp-Name`을 교차 검증하고 `server/discover`·`tools/list`에 cache hint를 붙입니다.
수평 확장per-request factory로 프로토콜 세션 저장소가 필요하지 않으며, Free 레이트리밋은 프로세스 공용 limiter로 보호합니다(다중 replica는 공유 limiter 필요).
호환성HTTP는 strict modern, stdio는 구형 클라이언트를 위해 `legacy: serve`를 선택적으로 지원합니다.
